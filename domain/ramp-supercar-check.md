# 超跑車道幾何適宜性檢查標準作業程序

## 1. 目的

本 SOP 整合台灣建築技術規則法規邊界與超級跑車底盤幾何極限，建立可在 Revit 模型中自動執行的車道幾何衝突檢核流程。

超跑在進出建築物地下停車場時，其前保險桿下擾流板（Front Splitter）、底盤中段排氣系統、後下擴散器（Rear Diffuser）極易因車道坡度轉折點設計不當而受損。本 SOP 提供三類衝突點的量化判定規則，並定義所需的緩和設計尺寸。

---

## 2. 法規依據

| 條號 | 內容 | 數值換算 |
|:-----|:-----|:--------|
| **§61** | 車道坡度：最大不得超過 1:6 | 16.67%、**9.46°** |
| **§61** | 服務車輛 ≥ 50 輛或機汽車併用坡道：坡度 ≤ 1:8 | 12.50%、**7.12°** |
| **§61** | 無障礙坡道：坡度 ≤ 1:12（常作緩和坡設計借鑒） | 8.33%、**4.76°** |
| **§61** | 單車道寬度 ≥ 3.5m | — |
| **§61** | 雙車道寬度 ≥ 5.5m | — |
| **§61** | 車道內側曲線半徑 ≥ 5m | — |
| **§60** | 停車位前方迴轉空間（60° 以上角度）：深 5.5m 或 6m、寬 5m | — |

> **設計原則**：法規規定的 1:6 坡度（9.46°）是上限，不是目標值。
> 針對超跑的車道，最大坡度的物理意義必須以超跑進入角（6.2°～9°）作為設計基準。

## 3. 超跑幾何規格資料表

### 3.1 關鍵幾何指標定義

| 指標 | 說明 | 衝突情境 |
|:-----|:-----|:---------|
| **最小離地高度（Ground Clearance）** | 車底最低點至地面之垂直距離 | 障礙物高度、水溝蓋高低差 |
| **進入角（Approach Angle）** | 前輪接地點→前保桿最低點切線角度 | 起坡點（Sag）：平地轉下坡，前保桿觸地 |
| **離去角（Departure Angle）** | 後輪接地點→後擴散器最低點切線角度 | 後退下坡、駛離上坡平台，車尾觸地 |
| **跨越角（Breakover Angle）** | 前後輪接地點→車底中央最低點切線角度 | 坡頂（Crest）：車底中段卡底 |
| **軸距（Wheelbase）** | 前軸中心至後軸中心距離 | 緩和坡最小長度計算基準 |
| **車寬** | 含後視鏡展開寬度 | 轉彎掃掠空間計算 |

### 3.2 代表性超跑規格資料表

| 車型 | 最小離地高(mm) | 進入角(°) | 離去角(°) | 跨越角(°) | 軸距(mm) | 車寬(mm) |
|:-----|:-------------|:---------|:---------|:---------|:--------|:--------|
| McLaren 750S | 107 | 8.3 | 13.3 | 11.5 | 2450 | 2161 |
| Porsche 911 GT3 RS | ~100 | 6.2 | 9.8 | 10.6 | 2457 | 1900 |
| Ferrari 296 GTB | 110–120 | <8.0 | <12.0 | <11.0 | 2600 | 1958 |
| Lamborghini Revuelto | ~110 | <9.0 | <13.0 | <10.0 | 2779 | 2024 |

> **保守設計原則**：工程師不得預設車主會在每次進出時啟動前軸抬升系統（Front Lift System）。
> 所有檢核必須以「標準靜態離地高度 + 滿載」為最惡劣輸入條件。

## 4. 幾何衝突類型與判定邏輯

### 4.1 第一類衝突：起坡點（Sag）— 進入角不足

**衝突情境**：車道由平地（0°）直接轉入 1:6（9.46°）下坡，前保桿下擾流板觸地。

**判定公式**：
```
Δθ_sag = θ_ramp - θ_approach_vehicle

若 Δθ_sag > 0 → 發生衝突（前保桿觸地）
若 Δθ_sag ≤ 0 → 安全（有正向餘裕）
```

**以 Porsche GT3 RS（進入角 6.2°）對應 1:6（9.46°）坡道為例**：
- Δθ = 9.46° - 6.2° = **+3.26°** → **衝突**

**緩和坡設計（多段分解法）**：
- 插入 1:12（4.76°）過渡坡，將單一 9.46° 轉折拆解為兩個轉折：
  - 轉折一（平地→1:12）：Δθ = 4.76° < 6.2° → **安全**
  - 轉折二（1:12→1:6）：Δθ = 9.46° - 4.76° = 4.7° < 6.2° → **安全**
- **緩和坡最小長度**：必須 ≥ 最大軸距 + 安全餘裕
  - Lamborghini Revuelto 軸距 2779mm → **建議 ≥ 3500mm**

### 4.2 第二類衝突：坡頂轉折（Crest）— 跨越角不足

**衝突情境**：車輛由 1:6（9.46°）上坡頂端進入平地，底盤中段卡底（Bottom Out）。

**判定公式**：
```
Δθ_crest = θ_ramp - θ_breakover_vehicle

若 Δθ_crest > 0 → 衝突（車底中段觸地）
若 Δθ_crest ≤ 0 → 安全（但 < 2° 餘裕視為警告）
```

> **警告**：Porsche GT3 RS 跨越角 10.6° 對應 1:6（9.46°），理論餘裕僅 1.14°。
> 考慮滿載懸吊下沉（約 5–10mm）與混凝土施工誤差（±3mm），此餘裕極度危險，
> 必須配置緩和坡或豎曲線。

**豎曲線設計（Vertical Curve）**：
- 以拋物線平滑連接上坡與平地，消除銳角轉折
- 建議豎曲線長度 ≥ 5m，在任一瞬間切線角度不超過跨越角

### 4.3 第三類衝突：平面轉彎 — 掃掠空間不足

**衝突情境**：超跑寬大車體在最小內側半徑 5m 的彎道行駛，內輪差壓路緣石，外側車頭逼近牆面。

**掃掠空間估算（簡化阿克曼模型）**：
```
外側掃掠半徑 ≈ √(R_inner² + L²) + (w/2)
內側最近點  ≈ R_inner - (w/2)

其中：
  R_inner = 內側曲線半徑（m）
  L       = 軸距（m）
  w       = 車寬（m）
```

> **注意**：此為簡化估算。精確值需 BIM 軌跡模擬（Autodesk Vehicle Tracking 或等效分析）。

## 5. 作業流程（AI 執行步驟）

### 前置條件確認

執行任何幾何分析前，AI 必須確認：
1. Revit 模型已開啟且含有車道元素（Floor 樓板或 Ramp 坡道）
2. 使用者已指定或同意採用預設超跑車型（vehiclePreset）

### Step 1：坡度合規性檢查

呼叫 `check_ramp_slope_compliance`：
- 偵測車道元素類型（OST_Floors / OST_Ramps）
- 量測各段縱向坡度
- 輸出坡度值（%、°、1:N）及法規對比結果
- 著色：**Pass** = 綠、**Warning（介於 1:8~1:6）** = 黃、**Fail（> 1:6）** = 紅

### Step 2：轉折點幾何衝突分析

呼叫 `check_ramp_transition_geometry`：
- 自動識別連續坡段之接合點（坡度突變位置）
- 分類為 Sag（起坡）或 Crest（坡頂）
- 計算轉折角 Δθ，對比超跑進入角/跨越角
- 輸出：衝突判定、安全餘裕(°)、建議緩和坡長度(mm)

### Step 3：轉彎半徑分析

呼叫 `check_ramp_turning_radius`：
- 識別車道曲線段
- 計算內側曲線半徑
- 估算超跑掃掠寬度
- 輸出：實際半徑、法規下限（5m）、掃掠餘裕

### Step 4：彙整報告與圖形標示

呼叫 `generate_ramp_compliance_report`：
- 彙整 Step 1–3 結果
- 批次套用圖形覆蓋
- 輸出結構化 JSON 報告

## 6. 附屬設施注意事項

### 截水溝蓋板
- 設置位置通常恰好在超跑進入角/跨越角最敏感的轉折點
- 傳統鑄鐵蓋板變形可造成 3–5mm 高低差，對離地 100mm 超跑為致命威脅
- 建議採用 FRP（玻璃纖維增強塑膠）蓋板，D400 承載等級，模組化安裝確保零高低差

### 車道鋪面
- 法規要求坡道表面防滑（建技規 §61 明定）
- 禁止使用起伏過大的卵石洗石子、深溝槽斬石子等粗糙面材
- 建議：表面平整度 ±3mm 內的均勻高摩擦係數樹脂系防滑耐磨地坪

### 減速設施
- 傳統減速丘（高度 > 50mm）對超跑為直接危害
- 替代方案：視覺減速標線、Speed Table（高度 < 50mm、寬長緩坡）
- 若採用 Speed Table，同樣須執行本 SOP 的進入角/跨越角檢核

## 7. 常見問題

### Q1：車道模型為多片樓板拼接，如何判斷轉折點？
工具會掃描相鄰樓板之接合邊，比較兩片樓板的坡度向量，計算其夾角作為轉折角 Δθ。

### Q2：建模時採用 Ramp 物件而非 Floor，工具是否適用？
`check_ramp_slope_compliance` 同時支援 `OST_Floors` 與 `OST_Ramps`，會自動偵測元素類別並採用對應的幾何讀取方式。

### Q3：超跑前軸抬升系統可以計入設計嗎？
不可以。依保守設計原則，所有幾何分析均以標準靜態離地高度計算，不得假設抬升系統已啟動。

### Q4：法規允許 1:6，但超跑要求更緩坡，是否需要修改法規？
不需要。緩和坡設計在 1:6 主坡道之前插入 1:12 過渡段，主坡道本身坡度不變，完全符合建技規。整體高程差也不改變。
